Tangential (zero only if uniform) v = v₀·eᵏᵗ + e⁻ᵏᵗ2  →  a_t = dvdt = 0.00
Total acceleration a = √a_r² + a_t² = 0.00

In uniform circular motion only a_r acts, so a = a_r and the particle keeps constant speed. In non-uniform circular motion a_t also acts, so the total acceleration a is always ≥ a_r — the speed is visibly stretching or shrinking as the particle goes around.
