Key Facts

  • Tension is maximum at bottom, minimum at top.
  • Speed is maximum at bottom, minimum at top.
  • String goes slack the instant T would go negative — object becomes a projectile.
  • v_top,min = √(gr), and by energy conservation v_bottom,min = √(5gr).
  • v_side,min = √(3gr) — this is a dual-purpose number: it's the minimum speed needed if the object starts at the side (horizontal point), AND it's the speed the object has when it passes the side, if it started at the bottom with v_bottom,min = √(5gr).
